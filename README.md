# 코드잇 Node.js 7기 PCCP 코딩테스트 스터디

코드잇 Node.js 7기 PCCP 코딩테스트 스터디 레포지토리입니다.  
함께 문제를 풀고, 알고리즘을 정리하고, 리뷰를 주고받으며 꾸준히 실력을 쌓는 것을 목표로 합니다.

---

## 스터디 규칙

### 1. 문제 추가
- 문제는 남은 문제가 **10개 미만일 경우** 추가합니다.
- 현재 풀고 있는 문제가 없다면 새 문제를 추가한 뒤, `chore:` 커밋으로 PR을 올려주세요.

### 2. 알고리즘 정리
- 각 문제 폴더 내 `algorithm.md` 파일에  
  **본인 이름을 작성한 뒤**, 해당 문제에 대해 본인이 생각한 알고리즘을 정리해주세요.

### 3. 문제 풀이
- 각 문제 폴더 안에 **본인 이름.js** 파일을 생성한 뒤 풀이 코드를 작성해주세요.

예시:
```bash
changho.js
seungcheol.js
kyungmin.js
dongwoo.js
``` 
### 4. 브랜치 규칙 
- 브랜치는 **본인 이름으로** 생성해서 사용합니다
예시 :
```bash
changho
```
### 5. 커밋 규칙 
아래 형식으로 커밋 메세지를 작성합니다 
```bash
feat: pccp lv1 001 붕대감기 풀이 추가
fix: 001 붕대감기 반례 수정
docs: 001 붕대감기 풀이 설명 추가
chore: 폴더 구조 정리
```
### 6. PR 규칙 
- PR을 올릴 때는 2명의 Approve 가 필요합니다
- 가능하면 **리뷰 코멘트도 함께** 작성해주세요.

### 7. 주간 정리 
- 매주 월요일마다 각 문제에서 사용된 알고리즘을 함께 정리합니다.
### 8. 진행방식 진행 방식

각자 문제를 풉니다.

풀이 전/후로 algorithm.md에 접근 방식과 알고리즘을 정리합니다.

풀이가 끝나면 PR을 올립니다.

스터디원들의 리뷰와 승인 후 main 브랜치에 머지합니다.
