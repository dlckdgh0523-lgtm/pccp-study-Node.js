# 김승철
1. 먼저, cards1과 cards2가 goal을 달성하냐 마냐의 조건을 보고 if 문 먼저 작성했습니다.
2. 중복 반복문을 써서 card1, card2를 어떻게 비교하지?라는 생각만 있었습니다.
3. 그래서 문제를 계속 읽어보았고, 조건문을 보고 생각이 든 점이, 카드를 무조건 사용하고 넘어가야 되고, 단어 순서를 변경할 수 없으니, card1을 처음 비교해보고 goal이랑 안맞으면, 순서 변경이 안 되니, card2를 비교하고, card2도 goal에 해당하지 않으면 No 출력하면 끝이잖아 라는 생각이 들었습니다. 
4. 그래서 for문의 문자열을 하나씩 비교해보는 for of문이 생각났고, 이 반복문 안에서 3번과 같은 과정을 반복하면 해결될 수도?라는 생각이 났습니다.
5. 그리고 반복문 내에서 배열의 shift를 쓰면 첫 번째 인덱스 값을 비교하고, goal이랑 일치하면, 출력하고, 초기 배열의 2번째 인덱스의 값이 첫 번째 인덱스로 이동하고, 다시 비교하니까 굳이 for문을 또 안써도 되겠구나 생각이 났습니다.
