# 김승철 ( 제곱근 활용 - 에라토스테네스 체 알고리즘도 활용 가능하다 함 )
1. - 문제를 이해하고 내가 이해할 수 있는 의사 코드를 작성하기 까지 꽤 오랜 시간이 걸렸다.
2. 문제를 주석 처리하여 컴파일러 창에 붙여넣고, **문제는 이해했지만 로직을 작성하는 데는 오래 걸렸다.**
3. 20분 정도는 고민한 것 같은데, **약수 구하기 → 약수 갯수 세기 → 리미트 검증 → 출력 이렇게 로직의 방향**은 잡았다.
4. 그래서 이제 쉽게 풀리겠구나 하고, for문을 작성하는데, **number가 10만까지 존재할 수 있다는 조건을 보고, 10만번 연산을 비교하면, 로직은 통과되어도 테스트 케이스에 통과를 못 할 것 같다**는 생각을 했다.
5. 그래서 6, 7번 line처럼, 현재 고민 중인 조건과 약수를 구해놓고, 규칙을 찾아보려 했다.
6. 발견한 점은 1이라는 약수가 구해지면 무조건 number는 자동으로 약수로 정해진다는 것이었다.
7. 그래서 구글링을 해본 결과 많은 분들이 **약수 구하는 문제에서 제곱근을 사용하여 문제를 해결**하셨다.
8. 그래서 for 반복문을 사용하여 제곱근으로 풀기로 했다.
9. 비교하려는 수가 number까지, 수를 하나씩 증가시키면서 비교한다. 이때, count가 선언되고, 내부 중첩 반복문에서 선언해주면 같은 자리만 맴돌게 된다.
10. 비교하려는 수를 제곱해서 i보다 같거나 작을 때까지 수행한다.
11. **number의 제곱근이 된다면 비교하려는 수 하나만 약수로 취급하기 때문에, 갯수가 1만 증가하고, 나눠떨어지면 숫자 2개( 비교하려는 수, number )가 추가**된다.
12. 그 연산을 모두 한 후, **리미트 검증**을 한다. count가 리미트 보다 크면, 필요한 철근의 갯수는 제한된 공격력인 power가 될 것이고, 그렇지 않다면 연산된 count가 될 것이다.
**※ 문제에서 로직을 파악하는 연습을 아직은 더 많이 해야할 것 같다.**
